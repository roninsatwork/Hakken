Quality at Google: what it is, how it is measured and how long it takes to recover from a core update

Google judges quality for a whole website as well as for each page, from signals it gathers over months. That is why a site hit by a core update rarely recovers in days: the work is usually counted only when the next core update rolls out.

What it means for you

If your rankings fell in a core update, improve the pages that let the site down, then expect to wait for the next core update to see it — often three months or more. Your Rankings chart marks each update, so you can see which one moved you.
