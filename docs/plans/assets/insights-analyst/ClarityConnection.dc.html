Connection

Connect this website's Microsoft Clarity project. Hakken reads its figures each morning and keeps them, since Clarity keeps only three days.

Connect Clarity

1. Add Clarity's tracking code to your website, and turn on Consent Mode in Clarity so your cookie banner passes each visitor's choice. Since 31 October 2025 Clarity needs this for visitors from the UK, the EEA and Switzerland.

2. In Clarity, a project admin opens Settings → Data Export → Generate new API token.

Kept with your other connections, never shown again. Hakken checks it straight away.

Clarity allows 10 requests a project a day and gives out the last three days only. Hakken asks once or twice each morning and keeps the history itself.
