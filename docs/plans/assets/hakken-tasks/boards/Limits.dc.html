Hakken tasks

What each person can ask Hakken to keep doing for them: alerts, reports and finding out why. Every task that is on runs a check each day, so this keeps the daily work, and its credits, in proportion.

Tasks on at once, per person
How many Hakken tasks one person can have switched on. Paused and deleted tasks don't count. When someone reaches it, Hakken tells them and suggests pausing one.Credits show in Usage, under Hakken tasks.Conterra Opshas its own number: 50 tasks

Changes apply straight away. At the limit, Hakken kindly asks the person to pause one first.

Google data for each website

What the platform buys from Google, through DataForSEO, for each website: a company’s own sites and every competitor it watches. Higher numbers give fuller lists on the Discovery screens, and cost more.

Keywords kept per website
The Google searches a website already shows up for, busiest first. Refreshed every week.About $0.15 to $0.22 a week for every 1,000. A site with fewer costs less.
Keywords re-checked every run
Of the keywords kept, how many get a fresh Google position on every run. The rest wait for the weekly refresh.About $0.15 to $0.22 for every 1,000, on every run.
Tracked keywords per website
Keywords checked on Google every run to see where the website ranks: the fan-out queries ticked on its prompts, plus any typed in on Tracked keywords. When it's full, nothing more can be added.About $0.003 a keyword, every run: $3 a run at 1,000.
Backlinks kept per website
Links to the website from other websites, strongest first. The number applies to each backlink list: links, linking sites, broken links, anchor text and servers.Up to about $0.06 for every 1,000, per list.
Competitors collected per website
How many of the competitors watched against a website are collected each run, the first added first. Past this, the run report names the website.Each competitor collected is paid for like a website of its own.
Days in a Search Console position
Search Console gives a website’s average Google position over a number of days. This is how many.No cost.

Changes apply from each website’s next run, or its next weekly refresh.

AI prompts

A prompt is a question we ask ChatGPT, Perplexity, Gemini and Claude for a company, such as “who are the best web designers in Surrey?”. Before answering, each AI searches Google: those searches are its fan-out queries. Searches that look up the same thing, typed in different ways, count as one topic.

Prompts per website
How many questions each website can ask the AIs. When it’s full, no more can be added. Set lower than a website already has, only its oldest are asked.About $0.07 a prompt, every run, asked of all four AIs.
Fan-out queries checked every run
How many of a website's fan-out queries can be ticked, across all its prompts, to be checked on Google every run. Each new one is still checked once without a tick. When it's full, no more can be ticked.About $0.003 a query, every run: $0.60 a run at 200.
Fan-out queries read per prompt and AI
For each prompt and each AI, how many of its Google searches we read, most repeated first. Past this, the AI searches page says there are more.No cost to read. Each new one is checked on Google once, about $0.003; after that only the ticked ones are, every run.
Wordings kept per topic
A topic is one thing the AI looked up, however it was typed: “best lead system for carp fishing” and “best lead systems for carp fishing” are two wordings of one topic. This is how many wordings we keep for each topic, most used first.No cost.
Topics on the AI searches page
How many topics the page lists, most used first. Only these are matched to a page (see Matching AI searches to pages).No cost to list. Matching uses AI.
Google AI Overviews bought per prompt
Google’s own AI answers on each prompt’s subject, with the searches Google ran for them, added as extra topics. Bought every 30 days. Off buys nothing.$0.10 a prompt plus $0.001 an AI Overview: about $0.20 a prompt at 100.

Changes apply from the next run. What the AI searches page shows changes straight away.

Matching AI searches to pages

After each run, AI checks which of the website’s pages answers each topic. A topic with no page is a missing topic, and can be suggested as a new page on the website’s To do list.

Topics checked in one batch
How many topics the AI looks at in one go.Uses AI. Changes how the work is split, not how much is done.
Topics checked per run
The most topics checked after one run. The rest wait for the next run.Uses AI: more topics, more AI cost.
Pages offered per topic
The website’s pages most like the topic, offered to the AI to choose from. 12 at most.Uses AI: more pages make each check bigger.
Site audit pages looked through
Of the pages the site audit found, how many are looked through when choosing pages to offer.No cost.
Ranking pages looked through
Of the pages the website ranks with on Google, how many of the busiest are looked through.No cost.
Missing topics suggested per run
New pages suggested on the website’s To do list after each run, most searched first. One dismissed or done never comes back.No cost.

Changes apply from the next run.

Search Console

What a company can track on its own websites' Search Console: the keywords and the pages it ticks to keep an eye on. Google charges nothing for Search Console, so these only keep the lists a size people can work with.

Search Console keywords tracked per website
How many of a website's Search Console keywords its company can tick to track. When it's full, no more can be ticked until one is unticked.No cost.
Search Console pages tracked per website
How many of a website's Search Console pages its company can tick to track. When it's full, no more can be ticked until one is unticked.No cost.
Countries kept ready per website
How many countries a website's Search Console keeps ready beside all countries, set on the Market page. Each one is collected at every collection, so choosing it on a Search Console page is as quick as all countries. Past it, the countries added first are kept.No cost from Google. Each country adds about 80% more requests to each collection, and storage in line with its share of the searches.

Changes apply straight away. At the limit, nothing more can be ticked.

Search Console screens

What the Search Console pages read, and the rules they decide by: how long a list is, when a keyword counts as new or lost, what counts as searched a lot. Google charges nothing for Search Console, so these only keep the pages quick and say every rule they use.

Rows a Search Console list holds
The most rows any Search Console list holds, the most clicks first: Keywords, Pages and every page built on them. Past it, the list’s footer says the list is longer.No cost. Longer lists take longer to open.
Rows on a keyword’s or a page’s own screen
The most pages a keyword’s own screen lists, and the most keywords a page’s own screen lists, the most clicks first.No cost.
Rows given intent and searches on a list asked of Google
A list for other dates, or for a country not kept ready, is asked of Google when it is chosen. Discovery’s intent and monthly searches, or a page’s type and estimated visits, are looked up for this many of the rows the page lists, the most clicks first. The rest show none.No cost. More rows take longer to look up.
Kinds of rich result whose pages are counted
Rich results counts how many pages Google showed in each kind of rich result, the kinds with the most clicks first. Google answers one kind at a time, so each kind is one more request after each collection. Kinds past it show no page count.No cost from Google. Each kind adds one request to each collection.
Countries beside a keyword’s or a page’s chart
How many countries “Where the clicks came from” shows beside a keyword’s or a page’s chart, the most clicks first. “Show all countries” opens the rest.No cost.
New and lost keywords read
The most new keywords, and the most lost ones, New and lost reads for the dates chosen, the most recent first.No cost.
Days watched before a keyword counts as new
A keyword Google starts showing the website for counts as new only once the website has been watched this long, so one Google simply hadn’t shown yet isn’t called new.No cost.
Days unseen before a keyword counts as lost
A keyword counts as lost once Google hasn’t shown the website for it in this many days.No cost.
Discovery keywords Missed demand reads
Missed demand reads this many of the website’s most-searched keywords in Discovery, to find those Google barely shows the website for.No cost.
Searches a month that count as searched a lot
Missed demand lists a keyword from this many searches a month.No cost.
Impressions under which a keyword is barely shown
Missed demand lists a keyword Google showed the website for fewer times than this in the dates chosen.No cost.
How far an estimate can be from Google’s clicks
Real against estimated calls Discovery’s estimate too high, or too low, when it is further than this from Google’s clicks, as a share of the clicks.No cost.
Positions the usual click rate is worked out for
Click rate by position, and Shown but not clicked, work out the website’s own usual click rate at each position from 1 to this.No cost.
Google updates listed
The most of Google’s updates the Google updates page lists, newest first.No cost.
Days read either side of a Google update
Google updates compares clicks and position this many days before an update began with the same number of days after it finished.No cost.
Weeks the weekly charts show
Position bands, Brand and non-brand, and New and lost show this many weeks.No cost. Position bands and Brand and non-brand change from the next collection.
Longest date range
The most days that can be chosen at once on a Search Console page. Google keeps 16 months.No cost. Longer ranges take longer to open.

Changes apply straight away, except the weekly charts and Rich results’ page counts, which change from the next collection.

Classifications per website
How many classifications a company may give a website's pages — its service lines, products, content hub.No cost.
Address lines per website
How many address lines (starts with, contains, is exactly, listed in a sitemap file) may catch pages for a website's classifications, all of them together.No cost.
Pages set by hand per website
How many of a website's pages may be given a classification by hand, or taken out of one. Past it, set more with an address line.No cost.

Keyword research

A company’s own lookups in Discovery → Keyword research: any search, its overview, Google’s results, its ideas and what the AI says. Each lookup is bought from DataForSEO by the Keyword research agent, within that agent’s own spend limit per run.

Keywords in one Look up
How many keywords can be typed into one Look up, one per line.Each keyword not already held costs about 5 cents: its overview, its last 24 months, Google’s top 100 and the top ten’s visits.
Keyword ideas of each kind
How many ideas a lookup buys of each kind — terms match, questions, and what the top pages also rank for — the most searched first.About 1.2 cents a kind, and 1.2 cents for each 100 ideas: about 5 cents for both kinds at 100.
Days a lookup is kept
How long a bought lookup is kept and reused. Looking a keyword up again within these days costs nothing; after them, Look up buys it afresh.Fewer days mean fresher figures, and more buying.
Google’s AI Overview searches per lookup
How many of the searches Google ran to write its AI Overviews are bought with What the AI says, the most run first. 0 buys none.About 10 cents a lookup, and a tenth of a cent for each search.

Changes apply to the next Look up.

Whole company

These two cover all of a company’s websites together, so a website can’t have its own.

Purchases per run
The most one run can buy for the company, all websites together. Each request to DataForSEO is one purchase. If it’s reached, the run stops buying and its report says so.A ceiling on what one run can spend.
Rows shown across all websites
How many rows Your prompts, Tracked keywords and AI searches show for all of a company’s websites at once. Past this, the screen says so; choosing one website shows everything.No cost.

Purchases change from the next run; rows shown change straight away.

Same for every company

One AI answer or one purchase serves every company that asks the same thing, so each of these is one number for all of them, set in System Settings → Limits.

Fan-out queries kept from one AI answer
The Google searches saved from a single AI answer. An AI normally runs a handful, so this is a safety net.No cost: they come with the answer.
Sources kept from one AI answer
Web pages an AI answer links to. AIs rarely link to more than a dozen.No cost: they come with the answer.
Businesses kept from one AI answer
Companies and brands an AI answer mentions, in the order it names them.Uses AI: each one is judged for how the answer speaks of it.
New websites noticed per purchase
Websites a competitor purchase meets for the first time, suggested as possible competitors. Past this, they are rarely useful.Uses AI: each one is judged as a possible competitor.
Google AI Overview searches kept per purchase
Searches Google ran for its AI Overviews on one prompt’s subject, most used first.No extra purchase. Each new search is judged once by AI.
Rows in one download
The most rows one downloaded file holds. The largest choice is about as much as one file can carry.No cost.

Changes apply to the next answers and purchases read; downloads change straight away.
