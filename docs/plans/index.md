# Plans

On 2026-07-20 all previous plans were retired to start fresh. There are now two
active plans, split by area. Together they are the single source of truth for
current work.

## Active Plans

- [Movement Definitive Plan](./active/movement-definitive-plan.md) — the vision,
  acceptance rules, capture-screen rules, and work queue for all movement work.
- [Platform Hardening Plan](./active/platform-hardening-plan.md) — correctness,
  security, operational envelope, agent runtime, and reusability work for the
  platform core. Explicitly excludes the movement demo, which stays as-is.

The two plans do not overlap. If work touches movement, the Movement Definitive
Plan wins; otherwise the Platform Hardening Plan wins.

## Retired And Completed Plans

Everything in [completed/](./completed/) is historical reference only. Retired
plans carry a note at the top pointing back to the Movement Definitive Plan.
They should not be treated as implementation instructions unless a plan is
reopened deliberately.
