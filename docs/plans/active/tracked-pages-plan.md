# Tracked pages — agreed 2026-10-03

What a company tracks, each list on a page of its own, from the menu.

## Why

Anthony, 2026-10-03: "we have the options to track keywords and pages and ai
queries in sites and search console, but we don't have a way to see just those
tracked items off the menu … I think this is a good set of screens to have."

## His decisions

1. **Each section's tracked lists stay its own.** "Tracked in search console
   stays in search console and vice versa": ticking a keyword in Search Console
   never tracks it in Sites, and adding a search in Sites never ticks it in
   Search Console. They differ in cost — a Sites check is bought from
   DataForSEO, Search Console is free — and in limits.
2. **Option A: a page per list, inside its own section.** Not one joined page
   across both sections.
3. **"Your searches" stays** where it is, under its name. It already lists
   only the searches the website tracks (each checked on Google every run), so
   Sites gets no Tracked group and no second copy of it; "Mentions" likewise
   already is the AI prompts' page.
4. **Drawn first** (the Search Console canvas, boards 19–21, "Tracked: only
   what you track"), with ronins.co.uk's real figures shown as if ticked, then
   "let's build this so we can get the foundations in place".

## The pages

- **Search Console → Tracked** (a new group, first in the menu, open on
  arrival; the other groups fold as since 2026-10-03):
  - **Tracked keywords** — only the ticked keywords (up to 200): four figures
    for them together (clicks with the change on the days before,
    impressions, click-through rate, average position), a search box, and one
    table — clicks and change, impressions, CTR, position and places moved,
    pages, top page. Unticking a row stops tracking it.
  - **Tracked pages** — the same for the ticked pages (up to 100), with each
    page's keyword count and top keyword.
  - Both follow the page-wide dates, kind of result and country, and are read
    through the lists' own machinery (a `tracked` view): the ready-made
    periods where they serve, Google asked live where they don't.
- **Sites → Google results → Tracked fan-out queries**, after "Your
  searches": the fan-out queries ticked to check on Google every run — which
  assistants asked each, times seen, position, change, best, how it's doing,
  last checked. Ticking a fan-out query already adds it to the website's
  tracked Google searches (`addedFrom: "AI_SEARCH"`), so they also sit among
  "Your searches"; this page is the focused view of them.

Every row opens its record's own screen, whose back link returns to the
tracked page as it was left (dates, country, search, order) and says so —
"Back to Tracked keywords".

## Limits, said

- Search Console keywords tracked per website: 200 until set
  (`consoleTrackedKeywordsPerSite`); pages: 100 (`consoleTrackedPagesPerSite`).
- Fan-out queries tracked per website: the existing fan-out tracking limit
  (200 on ronins.co.uk).
