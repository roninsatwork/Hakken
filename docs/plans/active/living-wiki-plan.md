# The Living Wiki — Search, Bearings, Health, and the Round Trip

Status: **Planned 2026-08-17**, building immediately on Anthony's "make
a plan and do this". Four pieces from the calibrated brainstorm; the
fifth idea raised there (a read-only handbook view for company staff)
was a question about one of Anthony's standing rulings and stays

Owner: Anthony

## The phases

### Phase 1 — the quick switcher (≈1 day)

One key anywhere in the wiki (Cmd/Ctrl-K) opens a switcher: type a few
letters, jump to any page. Results show the matching sentence, not just
the name. House-styled overlay on the house layer system, arrow keys
and Enter, Escape closes. Mounted on the wiki's list, detail and map at
both heights, walled exactly as those screens are.

Acceptance: three keys reach any page from anywhere in the wiki; the
search snippet shows why a result matched; the wall holds per scope.

### Phase 2 — the local graph (≈0.5 day)

Under each page, a small map of that page's own neighbourhood — the
page, its links, its backlinks — click a dot to travel. Drawn from the
detail door's existing resolved links and backlinks: no new backend.
The big map shows the whole brain; this shows where you're standing.

Acceptance: the ego-map renders on any page with connections, dots
navigate, and a page with none shows nothing rather than an empty box.

### Phase 3 — health on every page (≈1 day)

A strip of chips on each page from what the platform already records:
when the Freshness Checker last verified it, whether an open question
touches it, its receipts count, its usage. HONEST BOUND, recorded up
front: no "covered by N checks" chip — exam questions do not name the
pages they exercise, and inventing that mapping would be a guess
wearing a fact's clothes.

Acceptance: a freshness-verified page says so with its date; a page
named by an open question wears the flag and links to it; chips come
from real fields, no model calls, no scans at read time beyond the
detail door's existing neighbourhood read.

### Phase 4 — the Obsidian round trip (≈1 day)

The export's mirror: a Vault tab on the import box accepts an Obsidian
vault as a zip (or a handful of .md files); each markdown file becomes
an imported document through the SAME road as every import — the
Distiller learns it, review-first is honoured where ticked (and stays
the enforced default on the platform shelf), [[links]] ride along in
the text and weave as they already do. Bounded per import; non-markdown
files are skipped and said so.

Acceptance: a small vault imports with its links intact and pages
appear through the normal distil road; a zip with junk in it imports
the markdown and reports what it skipped; review-first behaves exactly
as on every other import.

## Order and size

**≈3.5 build-days.** Each lands separately, each stoppable.
