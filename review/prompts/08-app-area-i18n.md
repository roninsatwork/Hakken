# Bring i18n to the pre-kit /app pages and raise the adoption floors

## Context

i18n adoption is 85% in the admin area (172/202 non-test tsx using `useTranslations`) but only 51% in the customer `/app` area (27/53). The pre-kit pages carry hardcoded English: optional module (not included in this copy) (no `useTranslations` at all; literals at lines ~61 and ~93 such as "Upload a pipeline CSV…" and "Generated by Hakken Intelligence Output Engine"), `app/sales-data/page.tsx`, `app/properties/logs/page.tsx`, `app/agentic-testing/page.tsx`. The en/it catalogs (`messages/en.json`, `messages/it.json`) are in perfect 4,868-key parity, enforced by `src/i18n.test.ts`; `scripts/check-messages.mjs` verifies literal `t('key')` calls resolve; `src/admin-i18n-adoption.test.ts` holds shrink-only adopter floors (admin 139, ui 22) that are now well below actual counts.

## Task

1. Migrate the four named pages (and any other `/app` non-test tsx without `useTranslations` — enumerate first) to `useTranslations`, adding keys to **both** `messages/en.json` and `messages/it.json` in the same change. Follow the namespace conventions of neighboring kit-era pages.
2. Write real Italian translations consistent in tone with the existing `it.json` entries — no English placeholders.
3. Extend `src/admin-i18n-adoption.test.ts`: add an `app`-root adopter floor, and raise the existing admin/ui floors to just below current actual counts so the ratchet has no slack (read the test's own docstring for how floors are meant to work).
4. Run `npm run check:messages` and the i18n tests.

## Constraints

- The catalogs must stay in exact key parity — `src/i18n.test.ts` enforces this.
- Do not touch the frozen demo pages or the public marketing surface unless already enumerated as adopters.
- No code comments; do not commit or push.

## Acceptance

- Zero non-test `/app` pages with hardcoded user-facing English (demos excluded).
- en/it parity holds; `check:messages` passes; new floors are within a small margin of actual counts.
- `npm run check` passes.
